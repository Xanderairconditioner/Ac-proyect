# Xander Air Conditioner

Spanish-first static website for residential and commercial air-conditioning installation in Puerto Rico.

## Preview

Open `index.html` in a browser. The site has no build step or runtime dependencies.

## Cloudflare Pages

Connect this repository to Cloudflare Pages with `main` as the production branch. Leave the build command empty and use `/` as the output directory. Attach `xanderairconditioner.com` after the page content and contact details have been approved.

## Current content

- Residential and commercial installation, serving all of Puerto Rico
- Client-provided logo and installation photos in `assets/`
- Phone and WhatsApp contact: 787-401-6446
- Brand names provided by the client: TMG, Midea, Airmax, Aircon, Carrier, and Gree
- Spanish metadata, canonical URL, Open Graph tags, sitemap, robots file, and HVACBusiness structured data
